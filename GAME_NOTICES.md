# Game firmware notices

The game firmware (env `waveshare-knob-1_8-doom`, the `doom` branch) is a
separate program from terraDial. It's installed in its own flash slot beside
the dial and started from Settings > About; the two share no code, only a
byte in NVS saying which slot to return to.

It links the Doom engine, so **the game firmware is licensed under the GNU
General Public License, version 3** ([text](licenses/GPL-3.0.txt)). The
engine's files are GPL-2.0-or-later, and version 3 is the one that's
compatible with ESP-IDF's Apache-2.0 licence, which is also in the image.

The terraDial firmware is unaffected and stays MIT ([LICENSE](LICENSE)).

## Source

The complete source for any game image we hand out is this repository, at the
commit or tag it was built from. Build it with PlatformIO:

    pio run -e waveshare-knob-1_8-doom

If you received a Knob with the game on it and can't get the source from
GitHub, ask us and we'll provide it, for at least three years from when you
got it.

## Installing a modified version

The Knob has no secure boot and reflashes over USB. To install your own build:

    pio run -e waveshare-knob-1_8 -t upload        # the dial, with the dial+game flash layout
    pio run -e waveshare-knob-1_8-doom -t upload   # the game, into its own slot
